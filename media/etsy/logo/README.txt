baraah-sites — shop icon & banner
=================================

Rebuild everything here with:  node tools/logo.js


WHAT TO UPLOAD WHERE
--------------------

Shop icon    Shop Manager -> your shop name -> Edit shop -> the square by your
             shop name.  Use any icon-*.png.  All are 1000x1000; Etsy's minimum
             is 500x500, so these are twice the floor and stay sharp.

Banner       Same screen, "Big banner".  Use banner-*-1600x400.png.
             If Etsy offers you the wide carousel slot instead, use the
             matching banner-*-3360x840.png.

Keep the icon and banner in the same colourway.


THE OPTIONS
-----------

Open options.png to see all sixteen at once.  Each is shown full size and then
at 48px as a rounded square and as a circle, which are the two ways Etsy
actually crops it.  An icon that only works large is the wrong icon.

Four shapes:

  monogram   "b." — the lowercase serif b with the brand dot as a full stop.
             Strongest at small sizes.  The recommendation.
  window     A browser frame with the b inside.  Says "websites" before anyone
             has read the shop name, which helps in a search grid.
  stack      "baraah / sites" stacked.  Best name recall, but it goes to mush
             at 48px — better as a profile picture than a shop icon.
  dot        The b reversed out of a filled circle.  The most legible of all
             four when tiny; means the least on its own.

Four colourways, all from the same palette as the websites:

  a  Ink     #0E0E10 ground, ivory mark
  b  Clay    #B4562F ground, cream mark
  c  Cream   #F3EBDD ground, ink mark
  d  Sand    #D8CFC0 ground, ink mark


RECOMMENDATION
--------------

icon-monogram-b.png  (monogram, Clay) with banner-a-1600x400.png (Ink).

Etsy search results are a wall of white product photos, so the terracotta
square is the one that stops a scroll, and "b." still reads at 48px.  The ink
banner then matches the portfolio site exactly.

If you'd rather the shop feel light and calm, use icon-monogram-c.png with
banner-c-1600x400.png instead.  Both are correct — it's a taste call.
